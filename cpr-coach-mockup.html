CPR Coach — design mockup

Three separate CPR algorithms. Red circle = metronome (pulses 110/min, with sound); number inside = timer of how long CPR has run. No cycle/compression counters, no pauses. The breaths ratio is always shown — including in the compact running view — so the guideline is never withheld.

This version adds: a compact "Breaths: 2 after every 30 compressions" reminder just above Pause/Reset in the running view (marked optional for adults), so no screen omits the breaths guidance. Plus Ben's earlier fix (babies breath technique sits in the gray table, not the blue box).

Spec rule: no screen omits the breaths guideline. The running view always shows a one-line breaths-ratio reminder (from the 30:2 ratio) above Pause/Reset — marked "Optional" for adults (hands-only is acceptable), plain for children & babies. The full sequence + technique remain in the pre-Start view. If vertical space is tight on the very smallest screens, the condensed technique line (grey) is the first thing to drop — the breaths reminder stays.
